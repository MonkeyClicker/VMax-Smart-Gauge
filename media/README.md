# Project Media

Photos and videos documenting the V MAX Smart Gauge hardware, wiring, installation, and testing.

- [photos/](photos/) — motor connections, GPS/network wiring, board terminals, enclosure, and boat installation photos.
- [videos/](videos/) — display demonstrations, startup, diagnostics, and boat-test recordings.

Use descriptive filenames such as `2026-10-07-gauge-can-wiring.jpg` or `2026-10-07-dockside-scanner.mp4`. Link relevant media from the documentation using relative paths.

Keep photos and video clips reasonably sized. For large videos, upload them to an external video host or a GitHub release and add the link and a short description in `videos/README.md`.
