# NMEA 2000 Data Plan

## Strategy

Do not assume that every theoretically available NMEA 2000 field is transmitted by the boat. Milestone 1 is to observe the actual network and document source addresses, engine instances, PGNs, update rates, and unavailable fields.

## Initial PGNs

| PGN | Name | Primary Use |
|---:|---|---|
| 127488 | Engine Parameters, Rapid Update | RPM, trim, boost when available |
| 127489 | Engine Parameters, Dynamic | temperature, voltage, fuel rate, hours, load/torque, engine status |
| 127505 | Fluid Level | fuel level and tank capacity when available |
| 129025 | Position, Rapid Update | latitude/longitude |
| 129026 | COG & SOG, Rapid Update | GPS speed/course |
| 129029 | GNSS Position Data | GNSS position/time/fix information |

## Expected Sources

The network currently contains at least:
- 2024 Yamaha V MAX SHO 250
- Garmin 106sv

Source addresses are dynamic and must be discovered rather than hard-coded.

## Engine Instance

The first scanner will record both CAN source address and NMEA engine instance. The application will initially select the detected single engine but the data model should not prevent multiple engine instances later.

## Freshness

Each decoded measurement should track its most recent update time.

Example states:

```text
VALID     value received within expected timeout
STALE     previously received, but no recent updates
NA        field is encoded as NMEA not-available
UNKNOWN   field has never been observed
```

A stale value must not continue to look current on the main gauge.

## Derived Values

These are calculated locally rather than assumed to be transmitted by Yamaha:

- MPH from SOG
- GPH from fuel rate
- MPG = GPS MPH / fuel GPH
- fuel used by integrating fuel rate over time
- trip average MPG
- performance tables by RPM/trim/speed/fuel rate

## Scanner Output

The first scanner should emit information similar to:

```text
PGN=127488 SRC=17 COUNT=10492 engine=0 rpm=742 trim=8
PGN=127489 SRC=17 COUNT=1048 engine=0 tempK=333.15 volts=14.2 fuelLph=2.7 hoursSec=1032120
PGN=129026 SRC=3  COUNT=10495 sogMs=0.0 cogRad=NA
PGN=127505 SRC=22 COUNT=104 levelPct=68.4 capacityL=189.3
```

The numerical values above are examples only.

## Capture Documentation

Actual boat captures will be stored under:

```text
nmea/captures/
nmea/pgn-notes/
```

For each observed PGN document:
- PGN
- source address
- engine/tank instance
- approximate interval/rate
- fields populated
- fields unavailable
- comparison against Garmin/Yamaha displayed value

## Library

Initial C++ parsing is planned around Timo Lappalainen's NMEA2000 library and the ESP32-specific CAN driver. Verify ESP32-S3 compatibility in our exact toolchain before treating the first firmware as production-ready.
